## 公网部署规则

正式入口：[tongye.me/Focuence](https://tongye.me/Focuence) · [aitoshuu.me/Focuence](https://aitoshuu.me/Focuence)。

1. **固定分工**：两个主域名的 DNS、HTTPS 证书和公网入口保留在阿里云 `47.103.120.24`；这 9 个项目的应用或静态源站统一在腾讯云上海 `122.51.59.89`。阿里按项目路径反向代理，浏览器保留当前访问域名；不得把访客跳到服务器 IP、`aitoshuu.art` 或另一个主域名。
2. **路径约定**：`/ArtDuo`、`/SonoScope`、`/FamilyTree`、`/Focuence`、`/OutSet`、`/CordIndex`、`/CoScroll`、`/LuBirth`、`/InfiDao` 是唯一正式大小写。纯小写和其他大小混写用 308 在同域归一；只改项目名前缀，保留子路径大小写、编码和完整查询参数。末尾斜杠沿用各项目路由约定；缺失静态资源返回真实 404。
3. **域名与代理**：链接、接口、canonical 和 OG URL（若有）使用当前公网域名。入口覆盖传入的代理头；源站只信任受控网关的原始域名和客户端地址。跨云 HTTPS 校验真实证书与 SNI，不能关闭证书验证。Cookie、浏览器存储和离线缓存继续按域名隔离；流式接口关闭代理缓存与缓冲。
4. **项目范围**：只调整本项目的源站目录、服务和精确路由，保留两个首页、其他项目、DNS、证书续期及安全规则。服务器迁移不改变网站名称、个人网站属性和页面内容。COS/CDN 使用已有不可变版本前缀，保留 MIME、编码、CORS、缓存和音频 Range；密钥、私有环境、数据库、日志及临时传输包不得进入 Git 或公开目录。
5. **发布顺序**：从已确认的源码或线上冻结版本生成产物，记录源码提交、release ID 和 SHA-256；先上传并逐文件核对腾讯候选，验证依赖与健康状态，再原子切换本项目版本链接或网关 include。共享 Nginx 修改前重新读取现网、备份受影响文件，通过 `nginx -t` 后才重载，保留可用回滚版本，不能覆盖并行维护。
6. **验收与交付**：两个域名分别检查正式、小写、大小混写入口、深层页面、查询参数、版本标记、JS/CSS 与项目关键功能，核实最终地址仍在本站，并确认请求实际到达腾讯。邻站和首页必须回归；新功能按本项目测试要求验收。清理本轮测试服务、临时访问凭据及传输包，记录实际未测项；仅将本轮相关文件 commit、push，核对远端提交后交付。

腾讯静态源站为 `/srv/focuence/current`，独立虚拟主机 `focuence-origin.internal`，配置为 `/www/server/panel/vhost/nginx/focuence-origin.conf`。发布对象是独立官网构建，浏览器扩展沿用自身打包流程。

本节为当前公网部署约定。旧文档或工具草案若仍把活动源站写成阿里，应按本节腾讯源站架构审阅后使用，不得直接覆盖现网。

## 三个入口

| 入口 | 日常操作 |
| --- | --- |
| 工具栏弹窗 | 默认当前聚焦：目标、留断点、继续一页；相邻地图入口；保留整理、资料与窗口 |
| 原生侧栏 | 当前聚焦与地图相邻；跨站资料候选及关联纠正、完整找回、可开启的返回提示与路径 |
| 完整页 | 默认当前聚焦；完整地图与关系例证核对；保留资料、回顾、任务模式、设置和数据管理 |

弹窗的短操作直接完成。需要持续管理时点“打开侧栏”；需要深入回顾时再进入完整页。恢复会复用当前窗口中已打开的页面，只新开缺失页面。部分失败会留下提示，重试不会重复打开已恢复的页面。每个任务最多保存 30 页。

“保存窗口”始终取当前窗口，“保存所选”只取显式勾选；保存框内可以调整成员，同一地址只保留一份。长备注默认展示最多三行摘要，继续任务在摘要之前，展开后保留全文及换行。编辑时取消删除会回到原草稿。

已固定和已经分组的标签页受到保护。GitHub 与 GitLab 多层子组的项目边界分别识别；弹窗和侧栏均可移除不合适的建议成员。建议绑定生成时的窗口、版本和每个标签页的身份；关闭、移走、导航、固定或手工分组后，相关建议会撤回。后台再次核验所选范围，拒绝过期请求，不静默减少成员；反馈使用实际结果，并就近提供撤销。

任务可以展开查看全部保存页面，继续按钮位于展开列表之前。页面排序仅改变扩展中的列表，不移动浏览器标签栏；每行显示排序依据，前台时长统计最近七天。缺少浏览器访问时间时明确显示本机记录回退或未知。

## 围绕目标继续工作

1. “新建任务”可以先只写目标，也可以从窗口或一组页面保存任务。每个普通窗口单独选择当前任务；选择时不会自动打开全部资料。
2. 展开“相关页面”，按目标与已确认资料查找候选。固定和已分组的页面也能参与关联。“相关 / 不相关”会记住你的判断，可撤销或重置；“保存到任务”另行加入最多 30 页的恢复清单。
3. “留断点”记录已做到哪里、卡点、下一步和继续页面。最近访问只提供带时间的线索，需由你确认。暂停或切换任务时可一起保存；编辑冲突会保留草稿并要求核对最新版本。
4. “继续一页”直接复用或打开继续页面；“恢复全部 N 页”处理整个保存清单。断点可以指向已确认相关但尚未保存的页面，全部恢复不会悄悄多开这一页。
5. “找回线索”查任务名称、目标、笔记、断点文字及页面标题/网址信息，支持当前窗口、保存任务、访问记录和全部资料。关键词先显示，语义结果逐批补充；可停止分析，失败后可重新查找。

当前任务表达你的目标，页面归属表达你已经确认的关系。共享页面没有明确任务时保持未知，模型建议不会改写历史。后台普通回收保留当前窗口绑定，真正退出并重启浏览器后，需要重新选择或继续任务。

任务列表的“任务管理”中可调整生命周期或关联记忆。当前任务卡的“暂停此窗口”只解除这个窗口的聚焦，不改变任务状态和浏览记录开关。有改动的断点编辑器按 Esc 或关闭会保留原文字，只有明确放弃才丢弃；保存失败后仍可重试。

侧栏的返回提示默认关闭。开启后，需要连续至少 5 分钟访问两个已确认的其他页面，每页至少 15 秒；未知、快速掠过、空闲、失焦和暂停会中断累计。每 30 分钟最多一次、每个本地日最多三次，只按实际展示计数。可返回、把当前页标为相关、忽略或本次任务不再提醒。它不会打开侧栏、发系统通知或强制切页。

## 响应与本地模型

规则建议先返回，不等待模型。按需使用弹窗下方的本机模型入口，由随包提供的 **BGE-small-zh-v1.5 q8** 在本机计算 512 维向量，补充保守的语义聚合。相同网址和文本输入复用持久缓存，模型闲置约五分钟后释放。

页面输入为标题、域名和清洗网址中的路径信息；任务关联另读任务目标，找回另读你填写的任务文字及查询。长笔记按重叠短段检索，原文完整保留。没有网页全文抓取或生成式大模型；组名由规则生成，向量用于匹配。中文短文本优先，跨语言、信息不足的标题和真实大规模资料质量仍需日常验证。初次加载与缓存命中耗时不同，不承诺固定秒数。模型不可用时显示失败并保留规则或关键词结果，保存、编辑与恢复继续可用。

## 路径、地图与一周回顾

前台停留来自浏览器窗口焦点、活动页面与设备 idle 状态，**不等于实际注意力，也不判断工作是否完成**。失焦、暂停、暂离、重启或缺少连续观察的间隔不会包装成专注时长。

地图的节点表示主题，箭头表示已经观察到的主主题先后关系；不表示语义相似或因果关系。多 tag 的时长平均分摊。侧栏点选次数按钮、完整页点选次数或连线，可以查看对应页面与时刻。“回看此主题记录”按主题筛选；例证中的“在路径中核对这次切换”定位同一次访问的两端，并可返回所选关系。片段已过期或超出当前列表时会明确说明。

今天、昨天和近七天由后台统一裁剪与聚合。地图、关系表、时间线概况使用所选范围内的完整记录；列表只展示最新 2,000 条，不影响统计。侧栏以所选主题及其直接前后主题组成局部图，次数可以查看访问例证。完整图保留全部主题，左右列明确表示先访问与接着访问；默认聚焦选中主题的直接关联，可切换全部连线，完整关系表始终保留。主题尺寸不编码时长，位置不表示语义距离。

日期切换期间显示加载，成功后一起更新日期和记录；失败保留原日期与数据，并可重试。侧栏展开完整地图会保留日期、所选主题及关系；有未展开的局部关系或已失效的对象时明确说明。

一周回顾显示连续七天、逐日前台时长、访问页数、切换次数及主题分布。新安装从真实记录开始；没有记录的日期显示零。继续线索只在证据足够时提供下一主题候选，否则优先找回最近页面或保存任务。

新增任务回顾区分“同任务内换页”和“跨任务切换”。同一 A→B→A 往返须出现在至少三个独立观察时段才显示为重复模式，并附时间、样本数与原记录入口；返回间隔不解释成心理恢复成本。通过 Focuence 找回同一资料至少分布在三个不同日期，才显示重复找回。恢复次数是操作记录，不是完成量。

## 从源码重建

需要 Node.js 22+、npm、Python 3.10+。首次构建需要下载固定依赖与公开模型，构建后的分析在本机运行。

```bash
npm ci --ignore-scripts
python3 scripts/download-model.py
npm run build
npm test
```

`package-lock.json` 锁定依赖；`model-lock.json` 锁定模型 revision、大小和 SHA-256。源码包不重复包含模型、生成的 worker 或 WASM；离线包包含全部运行资产。

需要另行制作离线包时运行 `npm run package`，`dist/` 会生成离线 ZIP、源码 ZIP、安装说明和校验文件。每个 ZIP 含内部文件校验清单和 `build-info.json`；其中 `sourceDirty` 标识是否包含未提交修改，`sourceTreeSha256` 标识该次实际源码快照，不能只靠 HEAD 提交号推断安装包内容。

开发时可直接加载仓库目录；修改推理 worker 后先重新构建，再在扩展管理页重新加载。

## 数据与后续边界

默认记录开启，暂离阈值 120 秒，历史保留 30 天，返回提示关闭。暂停记录也暂停自动观察、自动关联和提示；手动编辑、查找与恢复仍可用。任务、确认断点和手工关联不随历史自动删除。设置中分别提供清除历史、清除关联记忆和清除全部。

所有记录、任务、恢复结果和向量缓存保留在当前浏览器。没有账号、遥测或云推理。主动打开/恢复网页时，网页本身仍正常联网。JSON 导出是明文，包含标题、网址、任务文字、确认断点和手工关联；不包含查询、临时窗口绑定或模型向量。

2.5 保留原数据库名称，结构升到 5，加入独立材料表，保留浏览器访问缓存与导入游标；导出格式为 6，支持格式 2—6 导入。浏览器历史缓存可重建，不进入交换备份。旧任务、原文字与确认断点保留。导入前展示具体冲突；合并默认保留本机，整体恢复明确列出覆盖数量。覆盖与恢复前快照在同一事务完成，配额或事务失败保留原库。清除历史同时清理两种访问来源、导入作业与内部恢复点；不会删除 Chrome 自身的历史。外部备份文件由用户自行保管。

资料库中的链接和摘录是独立材料，同一来源可以保存不同选文。每份原文和笔记分别最多 20,000 个 Unicode 字符，超限保留草稿；重复材料可复用并关联新任务，新增笔记须明确追加。右键入口使用可选 contextMenus 权限，不注入脚本、不读取整页或可编辑区域。临时选文草稿在当前浏览器会话保留 15 分钟；正式材料可编辑、删除、导出和恢复，网页变化不会自动覆盖已保存原文。

自定义 tag、跨设备同步、整页全文抓取和生成式总结不在本轮范围。用日常浏览验证找回耗时、恢复操作数和关闭后接续情况，合成测试不代表真实效率收益。
