## 纳入的架构与模块

本轮采用附件已有实现，没有另行实现 UI 改版或新增产品功能。

| 模块 | 当前职责 |
| --- | --- |
| `background.js` / `src/activity.js` | MV3 生命周期、前台访问片段、暂离与未知时间、消息分发 |
| `src/text.js` / `src/grouping.js` | URL 身份、规则标签、项目边界、保守分组 |
| `inference/` | offscreen + worker、本地 BGE q8、单线程 WASM、按需加载与释放 |
| `src/store.js` / `src/analytics.js` | 本地 IndexedDB、Page/Segment/Task、历史转移和恢复线索 |
| `app/` / `popup/` / `options/` | 工作台、轻入口弹窗、设置跳转 |
| `scripts/` / 锁文件 / `licenses/` | 固定依赖、模型来源、构建与发布打包、第三方许可 |
| `test/` | 41 项记录、统计、分组与身份边界测试 |

运行原则：先返回规则建议，语义增强由用户触发；所有推理在本机；不读取网页全文；固定页和已有浏览器分组受到保护；前台停留不等于实际注意力。

- 源包的 43 项开发文件已纳入工作树，其中 4 个图标与旧版相同。根目录 README 补充了基线状态和验证来源，`.gitignore` 增加了生成文件规则。
