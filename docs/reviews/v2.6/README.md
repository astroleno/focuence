# 2.6 连续性与预测输入验收

日期：2026-10-28。基线：`204a679`。本轮由主线程实现和验收，未启动新的独立评审 agent。

**本轮功能通过验收：查找可连续使用，分组继续作为主要功能，下一步页面/任务预测与文字补全已接入可选 AI 服务，并保留本机回退。** DeepSeek 真实生成成功；OpenCode Go 当前服务请求失败，单独列明，不计为通过。

## 交付行为

1. 查找后打开页面、查看来源、翻页再打开另一条，不再被普通停留记录或标签激活打断。固定本次查找的文档身份、原始文字变体与排序时间；新来源不混入旧结果。原资料消失、待跳转、任务/材料改写、删除或站点排除仍阻止旧操作。
2. 当前聚焦增加“整理分组”入口，直达真实分组区域并保留键盘焦点。分组仍可预览、手选成员、应用、撤销；成员变化的旧预览不能执行。注意力地图继续只展示真实访问关系，推测不会写成地图事实。
3. 当前聚焦可按需建议下一步页面或任务。AI 只能选择本机提供的候选编号；本机分支说明保存、确认或已观察依据。查看任务不会自动切换意图，打开页面前再核对可用性。
4. 查找框与断点“下一步”支持文字候选。点击才生成，采用后才填入，断点仍须明确保存；新输入、关闭/重开编辑器、任务变化或替换请求不会被旧回包覆盖。
5. 设置支持自定义 Base URL / 模型 / 密钥，以及 OpenAI Chat Completions / Anthropic Messages。默认关闭，缺配置、无权限、超时、错误或格式无效时回退本机。密钥只留在扩展本机配置，不回传到普通状态、备份或仓库。

## 服务与实际限制

- CC Switch 中的 DeepSeek 旧配置模型为 `DeepSeek-V3.2`；该请求失败后，采用[官方当前接口说明](https://api-docs.deepseek.com/guides/anthropic_api/)中的 `deepseek-flash`，生产适配器真实验证通过。
- OpenCode Go 对旧 `deepseek-v4-flash` 返回 `410 ModelDeprecated`；按[官方模型列表](https://opencode.ai/docs/go/)更新为 `deepseek-v4.1-flash` 并提供会话标识后，服务仍拒绝请求。未更改账号区域、额度、账单或其他策略，也不自动把用户数据转给另一云服务。可先使用已验证的 DeepSeek，后续替换成用户自己的服务。
- 真实密钥仅在验证进程内使用，未写入测试浏览器、源码、报告或产物。原生扩展验证了缺站点权限的拒绝路径、禁用状态的配置保存和凭据隔离；未人工点选首次启用的浏览器站点授权提示。真实服务测试与原生权限测试分别记载，不能合称为“浏览器内云请求全链路已实测”。
- 本轮未重新验证 Windows / Edge 和长期真实使用；未部署官网，也未修改用户正在使用的浏览器配置。历史核心评审中的返回提示边界及旧继续线索的排除过滤建议不属于本轮已关闭项目，不宣称所有历史 findings 均已结案。
