# 2.7 本机运行日志与分析验收

日期：2026-10-30。基线：`c2c9140`。主线程执行，沿用 `main`；未启动 agent，未创建分支或 worktree，未部署公网。

**本轮日志功能验收通过，Ego 已重新加载真实 2.7.0 并开启本机日志。** 入口为“数据与设置 → 运行与记录”。本次补足排错与采用分析，不改变注意力地图、任务确认、分组和预测各自的含义。

## 可以看什么

- 采集正在记录、暂离、暂停、排除、无有效页面、失焦等状态及原因。状态变化记录，同状态最多每 5 分钟一次；不据样本条数计算注意力时长或采集成功率。
- 本机分析耗时、排队、缓存复用；AI 实际请求的耗时中位数/95 分位、成功/失败/取消和已报告 tokens。用量缺失显示“—”并列覆盖率，关闭 AI 的本机模式不算故障回退。
- 下一步资料展示后有没有打开页面/查看任务；下一步文字和查找文字有没有采用；候选是否原样保存到断点。采用只改草稿，手改和放弃不算原样保存，保存成功后才记保存事件。
- 分组预览、应用和实际撤销，以及选择/暂停当前聚焦、保存断点和继续任务。空撤销不算成功操作；暂停浏览记录后不新增这些行为事件。

按请求去重，只有本期有展示记录的后续行为进入采用比例，缺失或跨期记录单列。**采用不等于准确，也不能据此推断节省时间。** 本轮没有足够真实使用样本来判断长期收益。

## 存储与保护

独立 IndexedDB `focuence-diagnostics-v1`，不升级任务数据库。默认开启，最近 7 天、最多 5,000 条；队列最多 100 条。字段白名单只允许时间、随机编号、枚举、数量、耗时及 tokens，不保存标题、网址、任务/页面身份、输入/生成原文、密钥、任意异常或响应正文。日志不上传，不进入任务备份，可独立导出/清空。

写入不阻塞主功能；存储故障显示不可用或本次后台运行的丢弃数量。关闭/清空使旧请求作用域失效，晚回包不能补回。清除历史会清日志并保留其开关；清除全部恢复默认。单独清日志保留任务、浏览记录及 AI 配置。说明见 [PRIVACY.md](../../../PRIVACY.md) 与 [实现说明](../../DATA_AND_ARCHITECTURE.md)。

## 开销与实际边界

在已保留 5,000 条的原生 IndexedDB 中，20 次追加写入的中位数 **0.5 ms**、95 分位约 **0.6 ms**，读取全部约 **20.6 ms**。这是这台设备上的小样本验收，包含数据库操作，不代表所有设备或预测端到端耗时；主要功能不等待日志落盘。合成本机候选显示中位数约 4–6 ms，也不代表真实 AI 延迟。

Ego 本轮采集诊断报告 `active / multiple-focused-windows`，浏览器当时报告 7 个窗口同时聚焦。日志如实暴露这个原因，没有改变前台定义、注入访问片段或修复浏览器的窗口焦点。**Ego 跨页访问到地图转向仍未完整验收**，沿用 [2.6.1 的边界](../v2.6.1/README.md)。当前没有 AI 调用样本，tokens 显示未知；后续正常使用后才有真实采用与耗时统计。
