## 实现与失败处理

`popup/app.js` 复用已有 `operation` 与 `saveGuard.requestExit()` 处理交接；完整工作台入口沿用同一交接函数。`src/draft-guard.js` 由编辑器所有者在成功关闭/取消/保存时释放保护，确认放弃先移除提示，因此交接失败不会把未保存的当前输入误当作初始值。任务和材料编辑器回归通过：继续编辑保留内容，明确放弃后新开的未改动编辑器正常直接退出，材料类型重绘也保留草稿。

交接失败的错误与继续保存入口都可见：400×520 下保存按钮 bottom=507.5，400×600 下 bottom=587.5，均在视口内。保存进行中侧栏入口与字段禁用；保存失败后退出保护仍在，重试成功可见新卡，保存本身没有自动开始聚焦。

`app/app.js` 去掉读取完成后的二次回顶及仅用于该步骤的序号；初次导航的同步回顶保留。`src/task-memory-ui.js` 用真实任务库区分日常筛选无匹配和真正空库，沿用查看全部接口。没有增加运行依赖或改变数据结构。
