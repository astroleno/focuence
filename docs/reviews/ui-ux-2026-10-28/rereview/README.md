**优先级裁决：** 两人都发现 RR2，Emil 将其列为 P3，Lama 列 P2。本汇总采用 P2，因为它直接阻断本轮要求的“写目标 → 保存后看见 → 设为当前聚焦”，且空状态继续诱导重复创建。RR5 仅由 Emil 提出，主线程已复核 DOM、截图和保存接口：记录开关的视觉状态与生效状态缺少就近说明，按 P2 收录。其余相同根因合并，不把两个组件中的同类草稿丢失重复计数。

## 一项概念一致性待修复

**RR6 / P3：扩展地图缺少可见的时长口径。** 节点可见“13 分钟”等时长，`aria-label` 有“分摊前台时长”，普通视觉用户看到的图例却未说明“分摊后的前台记录，不等于实际注意力”。官网和访问路径已经说明此边界。来源为 Lama；主线程核对了完整图、侧栏下部和对应源码，确认是可见解释的差异，没有证据表明本轮时长计算错误。

建议在地图旁用同一句简短说明补齐，不新增专注分数、完成度或评判。该项单独不阻塞 UI/UX 通过，但保留待修复状态。

Emil 认可总体事实表达没有推断完成度或心理注意力；Lama 针对地图节点的可见时长提出更具体的解释缺口。本汇总采用这个较窄的 P3 判断，不将其扩大为计算或预测错误；该分歧不影响两人的不通过结论。
