## 方法与范围

浏览器使用 ego-browser 的单一隔离任务空间，真实加载本次源码和官网构建。扩展页面为项目已有的 `?demo=1` 合成数据模式，不读取用户扩展数据库或历史。地图夹具初始化时固定页面 `Date` 到 2026-10-28 13:00 +08:00，使已有的上午合成片段可见，未修改系统时钟。

保存失败通过临时组件夹具复用实际 `createTaskMemoryUI` 与既有 demo transport，仅让一次 `SAVE_CHECKPOINT` 返回错误；该注入没有进入产品。之后重试真实执行同一合成适配器的保存。原生后台的并发修订与窗口隔离仍由现有/新增行为测试覆盖，不把注入错误当成真实磁盘故障实验。

本轮中间验收还找出地图 SVG 重绘移除焦点的情况，已通过在重绘中恢复稳定 ID 修复。后续复验等待当前数据与布局完成，并强制重载最新源码，确认返回与尺寸变化都保留焦点。零页面夹具最后按任务名称定位，避免早于上午示例片段的真实时间导致排序假设错误；该次中间失败没有被记成新的产品缺陷。

本轮验证了九项 UI 修复；原生工具栏/侧栏宿主生命周期、屏幕阅读器、触摸真机、真实模型与历史授权、真实备份恢复及公网部署未重新执行，不以 demo 冒充。此前三方评审的后台检索和返回提示问题继续在原记录跟踪，没有被本次 UI 修复关闭。断点保护覆盖编辑器内 Esc/关闭与显式转换；浏览器强制销毁弹窗或进程不等于持久草稿功能，本次没有新增该承诺。
