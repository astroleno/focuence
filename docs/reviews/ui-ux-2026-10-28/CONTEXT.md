## 独立性与方法

- lama reviewer 使用 lama 路由及 Appllama 设计规范中适用于浏览器产品的层级、状态、导航和概念检查；不把 Expo/iOS 专属要求硬套为缺陷，不做外部竞品研究。
- emil reviewer 使用 emil 路由及 emil-design-eng，检查交互反馈、键盘/触摸、布局稳定性、文案与控制细节；不为评审增加动效或依赖。
- 两人读取相同的产品契约和主线程提供的合成数据浏览器证据，独立分析，不读取对方报告或互相传递 findings。由主线程在两份报告完成后复核、归并与排序。
- 产品定位依据用户已强调的注意力地图与聚焦，以及 `PRODUCT.md`、`DESIGN.md`。不能把前台时长解释为实际注意力或完成度，不能把候选、相关判断、保存清单与用户确认断点混为一谈。
- 历史三方代码评审问题作为已知背景，只有与当前可见体验直接有关且有证据时才纳入；不得把历史缺陷复述冒充本轮新发现。
