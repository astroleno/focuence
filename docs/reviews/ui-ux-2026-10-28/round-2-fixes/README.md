## 主线验收

“地图看去向 → 聚焦决定眼前任务 → 确认断点 → 继续一页”在当前版本中职责一致：

1. 新建/保存目标后能找到对应任务，用户明确选择后才成为当前聚焦。
2. 当前区优先展示目标、确认的下一步和“继续一页”；批量恢复与任务管理继续可用。
3. 已保存页面的任务可确认 ESP32 文档为继续页，留下“从 ESP32 文档继续核对采集方案”，再成功接回一页，目标与断点保持一致。
4. 地图中 09:45 的“视觉创作 → 声音与硬件”可以核对摄影参考与 ESP32 文档这次切换的两个片段，随后返回原关系并继续键盘操作。
5. 从地图或长设置页回到当前聚焦，当前目标进入视线。主题、任务、分组及记录设置仍分别管理。

- 最后源码变更后重新运行 `npm test`：**153 通过、0 失败、0 跳过**。

- 一条中间失败保留原记录及 `resolvedBy`：测试改变 select 值时未先聚焦该控件，错误预期它已获焦点。后续先聚焦再操作的同分支通过；缺失关系的说明在两次记录中均正确。

- 10 个源文件指纹与两位 reviewer 独立核对的版本一致；代码语法、差异空白及文档/截图引用在交付前核验。
