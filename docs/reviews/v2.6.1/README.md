# 2.6.1 预测关联性与聚焦连续性验收

日期：2026-10-29。基线：`8b9447e`。本轮由主线程完成，没有新增 agent、分支或 worktree。

**预测修复、文字补全、分组与查找回归通过；Ego 已重新加载真实 2.6.1。Ego 的跨页前台访问到地图转向仍未完整验收，不能把隔离浏览器通过当成这一项也通过。**

## 修复与概念边界

1. **原 P2：本机建议混入摄影页面与浏览器任务，已修复。** 当前继续页、保存资料、人工确认关系排在前面；跨任务需要文字关联或共享确认资料。移除强行加入其他任务、凑满四项的逻辑；仅“任务、整理、检查”等通用词不构成关联。
2. 有效的“相关页面”分析结果可以进入下一步候选。实际本机 BGE 找到音频播放资料后，无需先手动确认即可看到它；界面标明“语义关联 · 尚未确认”。预测没有写入确认关系、任务断点或地图边。
3. 文字补全最多两条，保留输入前缀，过滤近似重复、网址和过长续写。下一步续写最多增加 120 字符，查找续写最多增加 80 字符；不会把过长答案硬截成半句。采用只填草稿，仍需明确保存。
4. 下一步请求的输出上限由 1,000 收紧至 450 tokens；文字补全为 400。仍只在点击时请求一次，保留自己的 API 接入与本机回退，没有新增后台请求或生产遥测。
5. 导航、关闭、排除、任务版本和关联依据变化继续拒绝旧建议。AI 合法返回空候选时接受空结果，不再强行回填本机候选。

## Ego 地图的实际边界

自动化空间仍不能稳定保持前台。另建的普通 Ego 验收窗口确实产生了一段约 **1.13 秒**的有效前台访问，地图出现 ESP32 主题节点；主题时长按标签分摊。第二页的观测已报告窗口失焦，因此没有形成这次跨主题转向。

所以本轮对 Ego 的结论是：**真实单页采集有正向证据，跨页转向、该转向的来源核对仍未完整验收。** 没有注入访问片段，也没有改成把后台浏览计为前台。隔离 Chrome 中完整链路已经通过，具体浏览器中的这项限制仍保留。

历史评审中的低频返回提示长时边界、旧“继续的线索”的排除过滤问题，本轮未扩展修复；本报告不宣称所有历史 finding 已关闭。
