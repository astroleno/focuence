# Focuence 公开官网与双域名部署

## 已确认目标

先完成 landing page 并验收，再部署到现有腾讯服务器。公开地址为 `https://aitoshuu.me/Focuence` 和 `https://tongye.me/Focuence`；两者使用同一份发布内容，访问时保留各自域名。现有主站和其他路径继续工作。

内容以注意力地图、当前聚焦和断点继续为核心，沿用现有白色、石墨色与蓝色焦点视觉。官网可公开，扩展 2.5 仍标记开发预览；不把尚未解决的核心评审问题当成已修复或稳定发布。

## 模块与接口

- `website/index.html`：中文官网、语义结构、安装入口、数据边界与常见问题。无脚本时仍可阅读正文及访问源码。
- `website/styles.css`：复用现有视觉语义，响应式、键盘焦点和减少动态效果设置。
- `website/main.js`：仅使用合成数据的交互示例。地图主题选择更新访问证据；地图、聚焦、断点可切换；示例目标、下一步与断点在当前页面内联动，不读取真实标签或历史，不持久保存输入。
- `scripts/build-website.py`：标准库构建，按明确清单复制官网文件与图标到 `dist/website/`，CSS/JS 使用内容哈希。资源路径固定在同源 `/Focuence/` 下，适用于两个域名及有无尾斜杠的入口。
- 服务器：沿用现有 Nginx 与 HTTPS。只添加 `/Focuence`、`/Focuence/` 的静态路径，发布目录与原站目录隔离。不做跨域跳转或 iframe 遮罩。配置备份、验证和原子切换后重载。

调查后确认现有两个域名共用阿里云公网入口，腾讯为另一台源站。因此保留现有 DNS 与 HTTPS，由公网入口仅转发 Focuence 路径到腾讯的独立静态站点。对应配置保存在 `deploy/nginx/`，不迁移原主站。

Focuence 的浏览器能力仍由本机扩展提供。腾讯服务器承载官网；官网示例不会把访问者浏览数据传到服务器。源码与安装入口指向公开仓库，不伪造应用商店或稳定版下载链接。

## 验收

1. 桌面和手机无页面级横向溢出，文字、按钮和图示可读，键盘可操作；减少动态效果设置得到尊重。
2. 三个示例视图可切换，主题选择、目标编辑、保存断点和继续示例都有可见反馈。空输入不进入虚假完成状态；刷新重置示例。
3. 地图明确表达访问先后与前台时长，不声称测量心理注意力，不制造专注分数。
4. 构建产物只含官网白名单资源，无源码仓库、模型、凭据、报告、过程文件或缓存。
5. 两个 HTTPS 地址及其带尾斜杠地址返回正确页面；资源完整，同一发布版本；`tongye.me` 地址不跳转到另一域名；原站入口响应保持一致。
6. 页面如实说明开发预览和本机扩展边界。保存部署/验证记录，清理临时截图、打包和调试文件。
