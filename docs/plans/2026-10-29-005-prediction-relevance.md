# 预测关联性与聚焦连续性迭代

基线：`8b9447e`。用户已确认执行上一轮四步计划，沿用 `main`，不创建 agent、分支或 worktree；验收后 commit / push。

## 目标、模块与接口

- 保持“真实注意力地图 → 当前聚焦 → 分组整理 → 找回与继续”。地图只表达前台访问证据；预测不创建访问、确认关系或任务完成事实。
- `src/prediction.js`：本机与 API 共用经过过滤的候选池。当前继续页、保存资料、人工确认关系优先；未确认的语义/关键词关联保留推测标识；跨任务需要文字相关或共享确认资料，不强制填满四项。没有当前任务时只保留达到既有样本要求的访问转向线索。
- 沿用 `work.association`，只消费当前任务、版本、窗口上下文仍匹配且对应标签快照有效的结果；不新增自动分析或后台联网。候选变化、导航、排除和任务修改继续使旧结果失效。
- `src/prediction.js`、`src/ai-provider.js`：文字补全保留输入原文，最多两条，要求简短且方向有区别，过滤近似重复和过长续写。每次点击仍只有一次请求，收紧本次生成上限；关闭或失败继续使用真实已保存文字。
- `src/prediction-ui.js`：就地展示确认来源与推测依据；采用只修改草稿，显式保存才更新断点。分组预览、手选、应用、撤销接口不变。
- 不新增生产遥测。验收脚本在少量合成请求中读取服务返回的 usage，记录时间与 token，不记录密钥或用户内容。

## 验收

1. 在 Ego 的实际可见普通窗口访问合成页面，验证前台片段、主题转向、来源证据、返回聚焦；若窗口无法保持前台，明确记录阻塞，不把人工注入数据计作通过。
2. 目标明确、目标稀疏、混有无关页面/任务、API 失败四类情形：保留相关来源，拒绝无关凑数；未确认关联可进入候选但不成为确认关系或地图边。
3. 页面导航、关闭、站点排除、任务/关联版本变化拒绝旧建议；文字前缀、输入变化、关闭重开、采用与保存边界继续通过。
4. 分组预览/手选/应用/撤销、查找继续使用的真实 MV3 回归，窄侧栏与完整页视觉验收；单元测试、扩展及网站构建通过。
5. 少量 DeepSeek 合成请求检查实际输出与时间/token 用量，清理本轮任务、缓存、临时凭据和过程文件，保留正式报告；不进行公网重新部署。
