# 注意力地图与聚焦主线：第二轮修复计划

2026-10-28。基准 `ee6a98a`。用户已授权按[独立复审汇总](../reviews/ui-ux-2026-10-28/rereview/README.md)修复全部 5 项 P2、1 项 P3、验收、Lama/Emil 独立复审，通过后在现有 main commit push，不分步询问。前序未提交的两份报告与证据作为本轮依据一并交付。

## 目标与已确认边界

主线为“注意力地图看去向 → 当前聚焦决定眼前任务 → 留断点 → 继续一页”。沿用原生 HTML/CSS/JavaScript、共享任务及资料组件和现有保存接口。保存目标与显式开始聚焦分开；主题、任务、相关判断、保存列表、浏览器分组和记录开关保持各自职责。此次不迁移数据库、不增加运行依赖、不部署公网。

## 模块设计与验收

| 项目 | 模块与关键接口 | 最终行为与验收 |
| --- | --- | --- |
| RR1 / P2 编辑退出 | 新增小型共享 `src/draft-guard.js`，以编辑快照判断改动；`requestExit(proceed)` 在无改动时直接退出，有改动时显示同一编辑器内的“继续编辑 / 放弃更改”。`app/app.js` 的任务编辑、`src/library-ui.js` 的手动/现有材料编辑及 popup 保存页接入；现有断点保护保留并回归。 | Esc、关闭、取消/返回不会静默丢文字或选择。继续编辑恢复原字段、光标与选择；明确放弃才退出。无改动直接退出；保存成功绕过保护，失败/冲突仍保留草稿；材料类型重绘不重置改动基准。原生宿主强制销毁不冒充持久草稿能力。 |
