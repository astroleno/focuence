## 目标、模块与接口

注意力地图解释已观察的访问关系，当前聚焦由用户选择，断点确认下一步，优先继续一页。沿用现有原生 HTML / CSS / JavaScript 和保存接口，不迁移数据或增加运行依赖。

| 项目 | 模块与设计 | 验收 |
| --- | --- | --- |
| SR1 / P2 草稿交接 | `popup/app.js` 的打开侧栏接入现有 `saveGuard.requestExit(proceed)`；交接复用 `operation` 的忙碌/失败反馈。确认放弃的点击中直接调用打开动作，之前不等待 RPC，保留原生侧栏用户手势。保存/交接进行中禁止重复离开。`src/draft-guard.js` 由编辑器所有者在成功退出时 `dispose()`，确认放弃先移除提示；若交接失败，初始快照和保护仍在。 | 未改动可直接交接；有改动先确认，继续编辑保留文字、光标和选择；明确放弃才跳转。合成交接失败保留草稿且再次退出仍有确认，成功重试可离开。保存中打开侧栏禁用。回归完整页任务与资料编辑器的关闭、继续编辑、明确放弃。 |

共享草稿保护的所有者已经在 dialog close 或 popup 取消/保存成功时释放保护。本次统一该生命周期，避免交接失败后将仍未保存的输入重新当作初始值。侧栏交接不承诺跨进程持久草稿；用户明确放弃后才离开编辑器。
