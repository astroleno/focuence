# 连续性、分组与预测输入

基线：`204a679`，在现有 `main` 工作区执行，不创建 agent、分支或 worktree。用户已批准继续实现、验收后 commit / push；已确认预测同时包括下一步资源/任务与文字补全，接自己的 AI API，保留本地回退。2026-10-28 追加授权：读取 CC Switch 的 Claude 项目下 OpenCode Go / DeepSeek 服务商配置，临时用于接入验证。

## 目标与边界

- 保持“注意力地图 → 当前聚焦 → 分组整理 → 找回 → 继续”的主线。分组是主要功能，保留完整预览、手选成员、应用与撤销。
- 修复查找结果打开后无法继续查找的问题；普通停留记录、激活页面和新增无关标签不应废弃整次查找。
- 新增下一步页面/任务建议、查找文字与断点下一步的文字补全。所有生成都是候选，用户接受后才打开、切换或写入输入框；不自动保存断点、移动分组或改地图。
- 本机 BGE 继续用于向量匹配。文字生成采用可配置 API，关闭、未配置、权限缺失、超时或失败时使用本机线索。
- 不扩展到这次目标之外的地图美化、旧评审全部建议或自动部署。

## 架构与接口

### 1. 查找连续性

涉及 `background.js`、`src/workspace.js`、`src/memory-search.js`。

- 区分普通观察与真实数据修改：观察追加和标签事件不增加全局数据版本；删除、站点排除、权限撤销、设置变化及显式任务/资料编辑继续失效与取消旧推理。
- 每次查找固定当时的文档身份。新增来源和无关页面不会混入旧结果；分页、来源、推理完成及打开操作重新核对原文档仍存在且允许访问。
- 文档身份由所属资料、字段和文本确定，不依赖合并来源的排列位置。被关闭且没有其他保留来源的页面、改写的任务/资料、移出筛选范围的来源不能继续操作。
- 分组仍在推理后读取真实标签，并在应用前校验成员快照；不得因放宽搜索失效而放宽分组保护。

### 2. AI 服务与数据

新增独立 provider / prediction 模块，后台接入；设置 UI 与共享文字候选组件调用后台，不在 UI 持有已保存密钥。

- 支持 OpenAI Chat Completions 与 Anthropic Messages 两种协议；Base URL、模型、密钥可更换。预设来自用户指定服务，密钥不写入源代码、报告、日志或构建产物。
- 配置独立存入扩展本机存储，不进入导出备份、普通状态响应或示例网页。设置页只读取 `hasKey`；清除配置/全部数据删除密钥。
- 请求服务前检查精确站点权限，按用户点击授权；仅 HTTPS（本机开发允许 localhost HTTP），禁止 URL 内嵌凭据与重定向转发密钥，设置超时和响应长度限制。
- `GET_AI_SETTINGS` / `SAVE_AI_SETTINGS` / `CLEAR_AI_SETTINGS` 返回脱敏配置；`PREDICT_NEXT` 返回候选及依据；`COMPLETE_TEXT` 返回完整候选文字、来源及回退原因。旧请求不得覆盖后来编辑或已关闭的界面。
- 只在明确点击“建议下一步/补全文字”时联网。资源建议发送当前任务名称/目标/确认断点与有限候选的标题、主题和候选编号；补全发送该输入内容及有限当前任务上下文。不发送完整历史、资料库原文、后台页面正文或 URL 参数。模型只可选择本机提供的候选编号，不接受模型凭空生成的地址。
- 返回前重新核对任务/配置版本、候选是否有效及站点排除。网络失败给出实际回退状态，不能把本机结果伪称为 AI 推断。

### 3. 界面

沿用现有浅色、低饱和强调色、字号和间距。聚焦仍为首屏，下一步候选放在当前任务与已有继续线索附近；分组入口与主流程保留。查找和断点下一步的补全使用就地候选与“采用/忽略”，支持键盘和窄侧栏，加载/错误不吞草稿，不增加装饰动画。

## 验收标准

- 查找 → 打开第一条 → 回来分页/看来源 → 打开第二条，记录开/关均可完成；普通 GET_STATE、激活和无关新页不清空结果。实际删除、排除、源文本变化、取消后晚回包仍被阻止。
- 分组主流程可预览、修改成员、应用并撤销；推理中页面跳转、成员关闭/已分组等拒绝旧建议。
- 两种协议有契约测试；用指定配置做少量合成文本真实服务验证，报告不含密钥。关闭/缺配置/超时/错误/无权限都有可用本机回退。
- 页面/任务建议与补全明确来源；不自动执行，人工采用有效；输入变化、切换任务、关闭弹窗后的旧回包无效。
- API 密钥不进入普通状态、备份、仓库或网页；网站示例不会发出外部 AI 请求。
- 全量单元测试、扩展和网站构建通过。真实原生检查与示例视觉检查分别记录，不互相代替。
