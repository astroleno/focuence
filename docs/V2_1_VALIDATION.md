# V2.1 插件界面验证

本页保留三层入口初版的验证记录。后续独立 Taste / Impeccable 审阅与重设计验证见 [UI 迭代记录](reviews/v2.1/README.md)；当前逻辑测试为 54 项。初版打包验证不代表本次重新打包，本轮没有生成 ZIP。

2026-10-22。初版实现范围为用户确认的三层插件界面；使用 taste-skill 完成一轮实施前截图评审，实施后进行功能与视觉验证。未增加分支、worktree 或 agent，未读取日常浏览器的资料与历史。

## 实现结果

| 入口 | 已实现 |
| --- | --- |
| 弹窗 | 规则建议、成员勾选、直接应用与撤销、保存一组或当前窗口、最近任务预览与恢复、可选本机语义增强 |
| 原生侧栏 | 独立窄栏布局、任务改名/备注/删除/恢复、当前页面同步、访问路径、时间筛选、主要五主题地图与具体切换证据 |

## 逻辑与原生插件检查

**51 项逻辑测试全部通过。** 新增覆盖本地日历与夏令时、跨午夜、多 tag 守恒、2,205 条记录下的完整聚合、恢复去重与继续页、最近任务排序、GitLab 多层子组边界。构建与离线/源码打包另行验证并输出文件校验清单。

在任务专用的 **macOS arm64 / Chrome for Testing 156.0.8078.47** 隔离配置中实际加载未打包 MV3 扩展。页面均为本地合成网页；七天历史为明确注入测试库的合成访问，不冒充真实工作时长。

1. 真实工具栏弹窗生成两组建议，全程不强制创建完整页。
2. 修改候选成员后，勾选框仍保留焦点。
3. 在弹窗内保存任务名称、备注及选定页面。
4. 应用原生浏览器标签组；其他候选保留；撤销恢复分组。
5. 弹窗调用随包的本机模型，模型进入 ready 状态。
6. 关闭一页后，预览准确显示缺页；恢复只打开缺页，重复恢复零新增。
7. 在隔离后台模拟一页创建失败；失败提示在重新打开弹窗后仍存在，重试只补齐缺页。
8. 真实点击弹窗打开原生侧栏；切换当前网页后侧栏同步。
9. 侧栏路径、轻量地图和选中箭头的具体访问证据可用。
10. 完整页展示七个本地日历日与主题概况。
11. 数据管理导出包含保存任务和版本化记录。

该流程没有未捕获的完整页或侧栏异常。验证中的浏览器与全部测试配置已关闭，未在用户日常浏览器中安装扩展。

## 视觉与键盘

- 弹窗固定 400px；实际原生弹窗受浏览器高度限制时，主区域滚动，底栏仍可见；表单输入不会把页头整体滚走。
- 示例界面覆盖 320/360/400px 侧栏、1440px 完整页与 390px 窄完整页，主要视图无横向溢出，也没有 `null / false / undefined` 残留。
- 任务编辑对话框获得初始焦点；Escape 关闭后回到任务入口。
- 地图连线支持 Enter 选择并保留焦点；展开完整地图携带所选时间范围。
- 保存当前窗口显式显示范围和 12 页预览；清空选择时不能提交，重新全选后完整保存。
- 实测代表性正文对比度 13.73:1、辅助文字 5.92:1、地图连线 4.42:1；辅助文字 13px。没有据此宣称全站读屏或无障碍认证。

## 实际限制

Windows / Edge、真实大批量页面的分类准确率、峰值内存和长期日常使用尚未实测。新 UI 没有新增自定义 tag、按任务筛选历史、JSON 导入、云同步或生成式总结。这些是后续独立设计，不属于本轮三层界面的已完成能力。

本轮原生验证数据与截图交付在输出目录；带 `demo` 的图片均为内存示例模式，带 `native` 的图片来自实际插件，但其中资料仍为合成测试数据。
