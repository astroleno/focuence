# V2.1.1 · 接续操作与状态修正

依据第二轮 Taste / Impeccable 独立评审及用户“继续迭代”的授权执行。沿用已确认的 MV3 扩展、本地规则与按需模型、现有数据结构及弹窗 / 原生侧栏 / 完整页分工；在 main 迭代并按既有要求提交、推送，不打包。

## 模块与接口

- `app/app.js`：任务保存入口显式传 `scope: window | selection`；分组仍传 `group`，编辑仍传 `task`。新建保存框按已有 URL 规范去重并支持勾选，限制 1–30 页，草稿在纠错中保留。后台 `SAVE_TASK` / `UPDATE_TASK` 协议不变。
- 日期加载独立保存请求范围与已加载范围。切换时仅显示新范围加载状态，成功才提交范围和数据；失败回到原范围，提供原请求重试。并发请求沿用 epoch 防护，不把失败或较旧响应写到当前状态。
- `src/task-notes.js`：共享备注摘要与展开控件。列表先呈现任务、页面落点与继续操作，再呈现有界摘要；展开保留全文、换行及稳定控件标识。弹窗和侧栏共用同一语义。
- `src/tasks.js`：提供保存候选按 `normalizeUrl` 去重的纯函数，校验口径与后台一致。只改变界面选择，不修改保存数据格式。
- 编辑中的删除确认保留原表单节点、字段及焦点；取消或 Escape 返回原编辑。异步提交期间阻止关闭和重复提交。
- `src/navigation.js`：完整地图 URL 增加可选 `topic` / `from` / `to`，沿用 `range` / `windowId`。目标界面核对对象是否仍存在，无效时说明回退。
- `src/map-layout.js`：局部图返回实际 `hiddenCount`；每方向两条的布局不变。侧栏的次数为明确的关系入口，指引不再承诺不可点击的连线。
- `popup/`：真实页面落点可单独打开；语义分析状态独立于保存 / 恢复，允许等待时切换最近任务和保存。后台模型架构不变。
- 共享应用补稳定筛选焦点、按筛选和暂停状态区分空态；窄侧栏标题与操作分行；任务名恢复对象标题语义，编辑保留独立按钮。

## 验收

1. 页面勾选 1 页后切到任务，“保存窗口”仍取整个窗口；“保存所选”只取显式选择。31 个不同地址能在保存框减至 30 页，不丢名称和备注；重复地址不虚增数量。
2. 今天 / 昨天 / 七天请求延迟、失败、重试及乱序时，没有新日期配旧数据的可操作状态。
3. 400×520/600 弹窗及 320×720、360×765 侧栏，短备注和 3000 字备注均能在首屏找到首项继续；全文可用键盘展开、收起且换行保留。
4. 编辑修改后，删除确认取消及 Escape 均返回原字段与焦点；保存 / 删除提交不能重复或在中途关闭。
5. Enter / 空格切换路径及页面筛选后，焦点仍留在该控件；真实空数据、零匹配和暂停文案准确。
6. 展开地图保留主题、入向 / 出向关系和日期；失效对象有明确回退。3+0、0+3、3+1、2+2、3+3 等关系组合的隐藏数量准确。
7. 弹窗、侧栏、完整页入口及原生分组 / 保存 / 恢复仍可用。一次批量检查，必要时集中修正并做至多一次视觉确认；修复后运行对应回归、现有测试和构建，交付截图及 Git 提交。
