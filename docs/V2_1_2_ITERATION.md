# V2.1.2 · 可信分组与就近操作

依据第三轮 Taste / Impeccable 评审、原生标签页验证，以及用户“你再迭代吧”的授权执行。沿用现有 MV3、本机规则 / 按需语义模型、弹窗 / 侧栏 / 完整页分工与视觉系统。在 main 提交、推送，交付截图，不打包。

## 模块与接口

- `src/proposals.js`：分组建议绑定唯一 `revision`、`windowId` 和逐标签页快照（ID、规范 URL、标题）。后台保存的版本是权威来源；客户端仅提交建议标识、版本和所选 ID。旧会话中没有快照的建议直接失效。
- `background.js`：`GET_STATE` 对照当前窗口撤回成员关闭、移动、导航、固定或被分组的建议，返回持续到重新生成的 `proposalNotice`。`APPLY_GROUP` 核验窗口、版本、完整原建议和所选子集，拒绝静默缩小操作范围；实际响应包含 `tabIds`、`count`、`name`、`groupId`。应用 / 撤销串行化。原生 API 不提供跨浏览器操作的原子比较交换，校验紧邻执行，不重试已改变的操作。
- `popup/` 与 `app/` 共用选择口径：展示的成员与可应用成员一致，选择按建议版本保存。后台拒绝过期操作后重新读取状态，提供重新生成入口。监听创建、关闭、移动、分离、附加、替换、固定、分组和导航；不在刷新中覆盖保存表单。
- 侧栏“页面”内增加“页面列表 / 整理建议”切换。主动生成后直接进入建议并定位标题；切回列表保留搜索、筛选、选择和滚动。建议展示全部成员，可逐页排除。完整页继续双栏。
- 弹窗成功反馈旁提供撤销；侧栏建议顶部保留撤销，并在应用反馈旁提供同一操作。失败和成功分别呈现，不用预览数量冒充实际结果。
- `src/task-pages.js`：弹窗、侧栏、完整页提供同一任务成员展开入口，继续操作位于展开内容之前；成员列表有界滚动，单页可打开，刷新保留展开状态。
- 列表排序说明仅改变当前列表；时长注明最近七天，行内显示相应数值；最近访问显示浏览器时间或明确标注的记录回退。保留 Chrome 120 兼容，不把缺失时间编造为当前访问。
- 内容按钮使用稳定标识；刷新恢复对应焦点，条目消失则回到当前区域的稳定入口。暂停状态保持可见。首次读取失败提供可操作重试。路径默认保留起点、时长和主题，详细区间按需展开。

## 验收

1. 真实浏览器中，将已建议的全部 / 部分标签移到另一窗口、关闭成员、导航、固定、手动分组后，旧建议不可执行，两个窗口均不被旧操作改变；未改变的其他建议保留。
2. 重新生成后可应用所选成员，返回实际数量；未选、固定及手动分组页不改变。撤销恢复原顺序，重复提交旧版本被拒绝。
3. 320×720 / 360×765 侧栏生成建议后首屏出现结果，全部成员可检查与排除；返回列表保留上下文。400×520 / 600 弹窗反馈与撤销同时可见。
4. 标签 / 任务页面按钮在外部标签变化刷新后保留焦点；消失条目有焦点落点。任务成员展开在刷新后保留，长列表不遮住自己的继续操作。
5. 排序依据、暂停状态、首次失败重试清晰；路径信息不重复堆叠，完整时间仍可查看。保留既有保存草稿、日期、地图接续与长备注行为。
6. 运行单元测试、构建及隔离浏览器的真实扩展回归。批量视觉检查后集中修正，至多一次广泛视觉确认；保留截图和结果。

本轮不改推理算法，不引入新权限 / 依赖 / 数据库迁移。任务成员编辑、跨界面草稿同步、浏览器标签栏排序与新预测算法仍属于后续功能提案。

原生 API 约束核对：[Chrome Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-group)（2026-10-23）。
