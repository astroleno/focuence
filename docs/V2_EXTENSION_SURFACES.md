# V2.1 插件形态：设计与实现边界

2026-10-22。依据用户本轮确认的三层形态实施：弹窗完成短操作，侧边栏承载持续操作，完整页用于深度回顾。Taste 截图评审先完成一轮，实施后做功能与视觉验证。

## 用户目标与入口

| 入口 | 主要任务 | 验收 |
| --- | --- | --- |
| 工具栏弹窗 | 直接生成、预览及应用分组；保存当前窗口或一组页面为任务；恢复最近任务 | 整理、应用、保存均不强制跳转完整页；保存范围与页数明确；恢复显示复用/新开数量；可撤销最近分组 |
| 浏览器侧边栏 | 保持网页可见，持续管理任务、查看访问路径和轻量地图 | 注册原生侧栏入口；切换当前网页后同步状态；窄栏独立布局；任务备注、路径和地图可操作；完整页入口可选 |
| 扩展完整页 | 最近七天回顾、完整地图、历史与数据管理 | 七天日期与指标口径明确；地图、关系表和时间线使用同一范围；保留导出/清理与设置；不因日常整理强制打开 |

## 模块与接口

- 继续使用现有 MV3 后台、IndexedDB、offscreen 模型与规则优先分组。弹窗、侧栏、完整页共享同一份真实数据与模型实例。
- `popup/` 为短操作界面，不再将规则分组结果转交完整页完成。新增保存表单、分组预览、直接应用/撤销、最近任务恢复。
- 新增 `panel/index.html` 原生侧栏入口；复用 `app/app.js` 的任务、路径及地图渲染与消息处理，以独立 shell 和 CSS 适配窄栏。
- `app/` 新增七天回顾视图，完整页保留全部分析与数据设置。侧栏与完整页通过本地扩展 URL 相互定位。
- `src/analytics.js` 增加日期范围及同源聚合：后台全量记录计算节点、边、概况与逐日数据；2,000 条限制只约束记录列表。
- 新增 `src/tasks.js` 提供去重恢复计划、最近访问页及任务排序；保存结构兼容新增 `lastRestoredAt` / `lastActivePageId` / `lastRestoreResult`，不重建旧数据库。恢复结果先持久化再激活页面，弹窗关闭后仍能看到未恢复页数。
- `GET_STATE {windowId, range}` 兼容旧调用，新增 `attention {range, summary, nodes, daily}` 及带恢复预览的任务。`range` 为 `today / yesterday / week`。
- `RESTORE_TASK {id, windowId}` 继续兼容，新增实际激活页和逐页失败结果；复用已打开页面，失败重试不重复创建成功页面。
- 原生侧栏由弹窗真实点击直接调用 `chrome.sidePanel.open`，不先等待后台消息而丢失用户手势；仅增加 `sidePanel` 权限。[Chrome 官方接口说明](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)。
- `app/demo-data.js` 继续只使用内存示例数据，并与真实界面使用同一套聚合和任务派生函数。示例截图不冒充原生扩展验证。

## 视觉与交互决定

产品的视觉线索是「从当前页面接回下一步」。弹窗先显示可执行动作与最近任务；侧栏以紧凑导航和纵向路径为主；完整页提供连续七天的事实回顾。

保留 Focuence 名称和现有图标。当前视觉迭代采用中性工作面、石墨文字、深色主要动作与少量蓝色焦点/选择，取代初版绿灰卡片；正文与辅助文字提高字号和对比度。减少重复边框、空白和状态文案。动效只解释加载、选中与操作结果，并尊重减少动态效果设置。

Taste skill 明确主要适用展示网站；本任务按用户要求采用其截图、层级、留白、字体与视觉纠错方法。营销页大图数量、夸张标题和多处入场动效不适用于插件，不作为本轮验收项。

具体组件与地图表达以 [当前 DESIGN.md](../DESIGN.md) 为准。独立评审与前后对照见 [本轮 UI 迭代](reviews/v2.1/README.md)。

## 验证边界

使用隔离的 Chrome for Testing 配置验证插件流程，不读取日常浏览器资料。验证弹窗分组/撤销、任务保存/恢复、原生侧栏打开与页面切换、完整页七天回顾及数据入口；补充涉及恢复、范围边界和大记录截断的逻辑回归测试。检查 320/360/400 px 侧栏、400 px 弹窗和桌面完整页的主要状态、键盘、溢出与可读性。

本轮不扩展为自定义 tag 系统、云同步或生成式预测。后续这些功能仍按各自数据模型与验收标准确认。
