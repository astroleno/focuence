开始之前，你可能想知道

这是网页应用，还是浏览器扩展？

Focuence 本体是 Chrome / Edge 扩展。这里是产品官网与合成数据示例；真实标签、当前任务和浏览记录由安装后的本机扩展处理。

安装需要做什么？

目前是开发预览，需要按仓库说明准备本地模型与依赖，再通过浏览器的开发者模式加载。安装步骤、权限和运行要求以仓库 README 为准。

打开安装说明 ↗
地图能知道我是否专注吗？

地图显示主题、访问先后和前台记录时长。这些是浏览线索，不能判断心理注意力、工作价值或任务是否完成。目标与下一步由你自己决定。

这里会收集浏览数据吗？

官网示例不读取浏览历史、标签或扩展数据，不使用分析追踪脚本。访问官网仍会发出正常的网页请求；扩展的数据处理边界请见仓库说明。

遇到问题，怎么反馈？

可以在公开仓库创建 issue。请说明操作步骤与浏览器版本，分享截图或日志前先移除私人网址和内容。
